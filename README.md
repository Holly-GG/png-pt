# Windows 本地产品图片工作台

在 Windows 10/11 x64 上安装 **Python 3.11 64 位**（包含 Python Launcher 和 Tcl/Tk），下载完整项目，双击 `start.bat`。首次自动建立独立虚拟环境并安装依赖，首次生成预览自动下载 rembg 的 **IS-Net general use** 模型（约 170 MB，保存在 `.models`，校验下载完整性）。需要访问 PyPI 和 GitHub release 下载地址。以后依赖和模型均复用；图片在本机处理，不调用图片云 API。

1. 选择输入目录和独立输出目录，或编辑 `config.json`。默认输出 `output_png`。
2. 点击“生成随机预览”，从待处理图片中随机选择 3 张，不足 3 张则全部选择。
3. 棋盘格只表示透明度；点击“查看原尺寸预览”检查边缘、Logo、文字、颜色与阴影。预览 PNG 在 `output_png/previews/时间/`。
4. 满意后点击“确认效果，开始批处理”，再次确认才会处理整个目录。若不满意，修改配置后重新预览。
5. 进度显示总数、已处理、成功、失败和跳过；失败详情追加到输出目录 `error_log.txt`。停止会等待当前图片完成。

扫描输入目录第一层的 JPG/JPEG/PNG/WEBP，大小写均支持；不递归以免误处理子目录。逐张 CPU 处理，模型只加载一次，适合几十至几百张；速度取决于 CPU 和图片尺寸。建议 8 GB 以上内存。支持 EXIF 方向及 ICC 转 sRGB，不复制原图 EXIF 到输出。

## 配置

路径可使用绝对路径（Windows JSON 示例 `"D:/产品图片"`）或相对项目目录的路径。输入、输出目录不能相同或相互包含。

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| input_folder | input | 原始图片目录 |
| output_folder | output_png | 透明 PNG 输出目录 |
| output_size | null | null 保持原像素比例并增加阴影透明边距；例如 [2000,2000] 则等比缩放、居中留透明边，不裁切或拉伸 |
| shadow_strength | 0.18 | 阴影不透明度 0~1，0 关闭 |
| shadow_blur | 12 | 柔化半径，原图像素，0~100 |
| shadow_offset | [0,2] | 水平、垂直偏移，原图像素，范围 -100~100；过大偏移可能悬浮，建议接近 0 |
| edge_refinement | 0.5 | 原图 alpha matting、过渡边缘柔化与去白强度 0~1，0 关闭 |
| brightness | 1.0 | 亮度倍数 0.5~1.5 |
| contrast | 1.02 | 亮度通道对比度 0.5~1.5 |
| sharpness | 1.08 | 清晰度 0~2，1 不变 |

启用边缘精修时，先用 closed-form alpha matting 重新估计主体边界透明度（求解长边最多 1400 像素以控制内存，最终仍使用原图 RGB）。精修采用保守的亮度通道调整、高光压缩和内部细节锐化，不使用生成式重绘，不重新生成文字或 Logo。对颜色要求严格时设 brightness、contrast、sharpness 均为 1。模型负责主体识别，不会简单删除主体内部的所有白色。

## 文件保护与重复运行

原图只读，不覆盖、删除或移动。`001.jpg` 输出为 `001.png`。同目录 `001.jpg` 和 `001.webp` 会造成同名冲突，工具在处理前拒绝开始，不偷偷改名或覆盖；请自行在输入副本中改名。

`.processed.json` 记录成功图片的 SHA-256、配置签名和输出 SHA-256。仅三者吻合时跳过。配置改变、原图改变、已有 PNG 缺少记录或被修改时，工具拒绝覆盖：请选择新的输出目录。不要手工删除记录后期待工具覆盖 PNG。处理失败可重试；若写出 PNG 后记录保存失败，该 PNG 同样受不覆盖保护。

预览必须全部成功才可确认。预览后的参数被冻结；修改配置要重新生成预览。处理开始时再次校验预览原图，避免确认陈旧效果。批处理中失败继续后续图片，错误写日志。

## 效果边界

单张图片的自动分割和落地轮廓推断不能保证摄影师级效果。透明玻璃、半透明包装、白色细线、镜面反光、复杂背景及裁切产品可能需要手工蒙版；请务必检查预览。接触阴影根据最低轮廓局部生成，不画统一黑色椭圆，但无法从二维照片知道真实三维地面；非落地、悬挂产品建议关闭阴影。背景空白区域为 alpha=0，产品及阴影使用自然半透明 alpha，棋盘格不写入 PNG。

没有真实产品照片时，自动化测试只能验证流程与图像不变量，不能替代实际效果验收。本项目未附模型权重；使用及商业分发前请查阅 rembg 和 IS-Net 上游模型许可证。

## 开发验证

Python 3.11：`python -m pip install -r requirements.txt`，运行 `python -m unittest discover -s tests -v`。
真实模型验证：`python tests/smoke_model.py`（会下载模型，使用合成样例）。验证范围见 `VALIDATION.md`。

GUI：`python app.py`。Linux 无桌面时只运行引擎测试。模型首次下载保持 TLS 和模型校验启用，不要设置跳过校验的环境变量。

此交付是 Windows Python 桌面工具，`start.bat` 负责安装与启动，并非无需 Python 的独立 exe。
